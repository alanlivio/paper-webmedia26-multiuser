# paper-webmedia26-multiuser

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Repository for the academic paper **NCL Users API: `gingaf` support and new proposed user attribute for `<rule>`**.

- `paper/` — LaTeX source
- `website/` — static webpage using Zensical

At `website`, do `make help` to see all available commands. The deployment to GitHub Pages is handled by [deploy.yml](.github/workflows/deploy.yml).
